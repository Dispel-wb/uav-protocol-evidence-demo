# 实际操作演示素材

`demo_recording.mp4` 是在浏览器中操作真实 Demo 录制的视频，并非界面动画。`keyframes/` 中的 8 张 1920×1080 截图按演示顺序编号，可直接用于答辩 PPT：

1. 正常捕获识别 7 帧；
2. 起飞指令字段与原始字节；
3. 修改高度阈值并重跑；
4. 异常捕获形成 3 项证据；
5. SBUS 16 通道；
6. SBUS 失控保护；
7. 同一捕获内识别两类协议；
8. 导出证据报告。

录屏所用输入均为 `samples/` 中随仓库提供的字节流。

`unknown_discovery_recording.mp4` 和 `unknown_keyframes/` 展示 V0.3 新增的未知协议发现：两族未知帧交错、已知与未知三族混合、候选字段与校验、单帧证据不足时拒绝推断，以及导出含结构假设的报告。这里的未知帧由测试脚本生成，其布局没有进入发现算法。
